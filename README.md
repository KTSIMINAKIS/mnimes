# Μνήμες

Δωρεάν εφαρμογή σε **ένα αρχείο HTML** που μαζεύει φωτογραφίες και βίντεο από φακέλους, δίσκους και USB, και τα τακτοποιεί ανά χρονιά, μήνα και μέρος. Έχει ημερολόγιο και χάρτη.

**Σελίδα:** https://ktsiminakis.github.io/mnimes/

- Μόνο αντιγραφή, byte-προς-byte, με έλεγχο SHA-256 σε κάθε αρχείο.
- Τα αρχικά σβήνονται μόνο αν το ζητήσεις, και μόνο αφού επαληθευτούν τα αντίγραφα. Ό,τι σβήνεις πάει πρώτα στον Κάδο.
- Τίποτα δεν ανεβαίνει στο ίντερνετ.

**Χρήση:** κατέβασε το `Mnimes.html` και άνοιξέ το με Chrome ή Edge σε υπολογιστή. Σε Safari, iPhone και Firefox κάνει μόνο προβολή.
